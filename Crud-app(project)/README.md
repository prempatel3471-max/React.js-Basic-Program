# CRUD Application

A simple CRUD (Create, Read, Update, Delete) application built using React.js.


## 🚀 Features

- ➕ Add new users
- 👀 View user data
- ✏️ Edit user information
- 🗑️ Delete users
- 📱 Responsive design
- ✅ Form validation

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- JSON Server
- React Hooks (`useState`, `useEffect`)

## 📋 User Fields

The application contains the following fields:

- Name
- Email
- Phone
- Gender
- Date of Birth
